# 拡張機能ごちゃまぜ

Chrome 拡張機能をまとめたリポジトリです。  
単体で使うものと、全機能を1つにまとめた統合版があります。

---

## 拡張機能一覧

| フォルダ | 名前 | 機能 |
|----------|------|------|
| [`便利ツール/`](便利ツール/) | 便利ツール | 広告ブロック + ダークモード + スクリーンショット |
| [`広告ブロック/`](広告ブロック/) | 広告ブロッカー | 広告ブロックのみ |
| [`強制ダークモード拡張機能/`](強制ダークモード拡張機能/) | 強制ダークモード | ダークモードのみ |
| [`スクリーンショット/`](スクリーンショット/) | スクリーンショット | スクリーンショットのみ |

---

## 各機能の説明

### 🛡 広告ブロック
- ネットワークレベル（`declarativeNetRequest`）でリクエストをブロック
- CSS・DOM レベルで広告要素を非表示
- サイトごとの除外リスト設定（ポップアップ・設定ページ）

### 🌙 強制ダークモード
- CSS フィルター（`invert + hue-rotate`）でページをダーク変換
- このサイトだけ ON/OFF できるサイト個別設定
- すべてのサイトに一括適用するグローバル設定
- ネイティブダークモード対応サイトは自動スキップ

### 📷 スクリーンショット
- **表示部分を保存** — 現在見えている範囲をそのまキャプチャ
- **ページ全体を保存** — スクロールしながらタイル撮影し PNG に合成
  - ヘッダーは1枚目のみ表示、2枚目以降は自動非表示
  - ファイル名: `screenshot-visible-YYYYMMDD-HHmmss.png` / `screenshot-fullpage-...`

## インストール方法

1. このリポジトリをクローンまたは ZIP でダウンロード
2. Chrome で `chrome://extensions` を開く
3. 右上の **「デベロッパーモード」** をオン
4. **「パッケージ化されていない拡張機能を読み込む」** をクリック
5. 使いたい拡張機能のフォルダを選択

> 複数インストールする場合は手順 4〜5 を繰り返してください。

## 技術仕様

- Manifest V3
- Chrome 109 以上推奨（`offscreen` API 使用）
- 権限: `declarativeNetRequest` / `storage` / `tabs` / `scripting` / `downloads` / `offscreen`（機能により異なる）
